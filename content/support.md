# Support

Direct, human support for every Aurelle customer.

## How to get help

- Read the documentation first. Most questions are answered there.
- Contact support: support@aurelletheme.com
- Typical response time: within 1–2 business days (24–48 hours).
- Support hours: Monday–Friday, 9:00–18:00 CET (UTC+1).
- Support language: English.

## What is covered

- Questions about how the theme's features and settings work.
- Bugs in the theme as delivered.
- Help with the theme's style and settings.

## What is not covered

- Custom code changes and third-party apps.
- Content, product photography and store configuration.
- Issues caused by edits to the theme's code.

## When you write to us, please include

- Your store address and the theme version (shown in the editor under Theme settings).
- What you expected and what happened, with a screenshot if possible.
- The page address where it happens.
